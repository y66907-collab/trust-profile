# Frontend

עוד לא נבנה. הכיוון: אפליקציית מובייל-ווב (Next.js או Expo), RTL, שלושה מסכים בשלב א':

1. **בניית פרופיל** — רשימת קוביות, מד השלמה, כפתור Connect לכל מקור
2. **שיתוף** — Preview של מה המקבל יראה, בחירת קוביות, תוקף, קישור
3. **צד המקבל** — `/s/{token}`, בלי הרשמה, כל פריט עם דרגת הוכחה

ועוד מסך קטן לממליץ: `/r/{token}` — שאלות סגורות, דקה אחת.
