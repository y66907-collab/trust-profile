# חיבור בכיף — איך כל מקור עובר את מבחן השירותים

**מבחן השירותים:** יד אחת, שתי דקות, בלי לקום.

**כלל הזהב:** המשתמש **רק מאשר ונכנס**.
- לא מוריד קבצים.
- לא מעביר מיילים.
- לא משתף.
- לא מצלם מסמכים.
- לא מקליד.

את כל השאר אנחנו עושים.

| **🔑 אישור** | לוחץ "אשר" | מקבלים את המידע ישר מהמקור |

| **⚡ אפס** | כלום | בודקים במאגר ציבורי ברקע |

## המקורות לפי סוג

### 🔑 אישור — עובד היום

| מקור | מה המשתמש עושה | ⏱️ |
|---|---|---|
| Google / Microsoft | בוחר חשבון | 5 שנ' |
| GitHub | "אשר" | 5 שנ' |
| טלפון | הקוד ממלא את עצמו, לוחץ "אשר" | 10 שנ' |
| ת"ז + סלפי | מכוון את המצלמה. הצילום אוטומטי | 45 שנ' |
| מייל עבודה | לוחץ על הקישור שהגיע | 20 שנ' |
| ממליצים | בוחר איש קשר ← "שלח" (וואטסאפ מהמספר שלו) | 30 שנ' |

### 🏛️ נכנס, ואנחנו לוקחים — "חבילת ממשלה"

**מה המשתמש עושה:**
1. לוחץ "חבר מסמכים ממשלתיים".
2. מזדהה פעם אחת (הזדהות לאומית), בתוך האפליקציה.
3. רואה פס התקדמות: "מביא תמצית רישום... טופס 106... ביטוח לאומי ✔️".
4. מאשר: "זה מה שייכנס לפרופיל. נכון?".

**מה אנחנו עושים:** פותחים את הדף הישיר של כל מסמך, תופסים את הקובץ כשהוא יורד, וקוראים אותו.

| מסמך | מה יוצא | ⏱️ |
|---|---|---|
| תמצית רישום | שם, שנת לידה, עיר | |
| טופס 106 | מעסיק, טווח שכר שנתי | |
| ביטוח לאומי | איפה עבד וכמה זמן | |
| **סה"כ** | | **~1 דקה** |

⚠️ **השאלה הכי חשובה בפרויקט עכשיו:** האם הזדהות לאומית עובדת בתוך דפדפן שמוטמע באפליקציה?
- במפה כתוב שהיא חוסמת.
- **אם היא חוסמת:** המשתמש יצטרך לפתוח דפדפן רגיל ולשתף משם, וזו פעולה. לכן צריך בדיקה טכנית של יום אחד לפני הכל.

עוד דברים לבדוק:
- ❓ האם ביטוח לאומי עובד עם הזדהות לאומית, או שיש לו סיסמה משלו.
- ❓ מה הקישור הישיר לכל מסמך.
- ❓ האם המסמכים חתומים דיגיטלית.
- ❓ חוות דעת: מותר לנו לבצע את הלחיצות בשם המשתמש באתר ממשלתי, כשהוא עצמו מחובר? ⚖️

### 🔑 חיבור תיבת מייל — אישור אחד, הרבה מסמכים

**מה המשתמש עושה:** "חבר מייל" ← "אשר".

**מה אנחנו עושים:**
- מחפשים **רק** מיילים מספקים מוכרים: חברת חשמל, עירייה, חילן / מיכפל, הבנק.
- לוקחים רק את הקובץ המצורף.
- לא קוראים שום מייל אחר.

| מה נמצא שם בדרך כלל | מה יוצא |
|---|---|
| תלוש שכר | שכר חודשי בטווח, מעסיק |
| חשבון חשמל / ארנונה | גר בכתובת מאז |
| אישור הוראת קבע (אם נשלח במייל) | משלם שכ"ד |
| חוזה שכירות (אם נשלח במייל) | איפה גר ומתי |

**מחיר ותהליך:**
- **Outlook:** קל יותר. אין בדיקת אבטחה חובה.
- **Gmail:** צריך בדיקת אבטחה שנתית (CASA), $540–1,800 לשנה. גוגל מאשרת לאט.
- ⚠️ גוגל אוסרת שימוש בנתונים "לבדיקת כושר אשראי" ⚖️.

## מה עושה את זה כיפי

- **"+8% ✨" אחרי כל אישור**, עם תג שנדלק.
- **"ככה יראו אותך"**: תצוגה מקדימה שמתמלאת חי.
- **אנחנו עובדים, הוא מסתכל**: "מחפש תלושים... מצאתי 3 ✔️".
- **אפשר לעצור תמיד.** הכל נשמר.
- **מה שחסר לא מופיע.** אין אזהרות.

## הצעד הבא

**בדיקה טכנית של יום אחד:**
1. אפליקציה ריקה עם דפדפן מוטמע.
2. בודקים אם אפשר להיכנס בתוכו עם הזדהות לאומית, ולהגיע לתמצית רישום, לטופס 106 ולביטוח לאומי.
3. בודקים אם אפשר לתפוס את הקובץ שיורד.

**אם זה עובד:** רוב הפרופיל עומד בכלל "רק לאשר".
**אם לא:** צריך להחליט על פשרה.
